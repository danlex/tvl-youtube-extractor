1 One-line install

The Claude Code skill & command

The fastest way — adds the /tvl-extract command and the tvl-youtube-extractor skill to Claude Code. Paste this in your terminal:

# clones to ~/.tvl-youtube-extractor and wires up the command + skill
curl -fsSL https://raw.githubusercontent.com/danlex/tvl-youtube-extractor/main/install.sh | bash

Then, in any Claude Code session:

/tvl-extract https://youtu.be/VIDEO_ID Romanian

Or just ask Claude: “summarize this YouTube video: <url>” — the skill runs it for you.

2 Prerequisites

What you need

ToolWhy
yt-dlp, ffmpeg, ffprobedownload the video, cut frames & clips
Claude Code (logged in) or ANTHROPIC_API_KEYthe agent that maps the story & translates
Python 3.10+the backend
Node 18+ (optional)only to build the web UI — not needed for the CLI/command
# macOS
brew install yt-dlp ffmpeg

Transcription needs no setup. It uses the video's YouTube captions when present, and falls back to faster-whisper (installed via pip, runs int8 on CPU) when there are none. No whisper.cpp required.

3 The full app

Run it locally

Clone the repo and start everything with one script — it builds the UI, sets up a Python venv, installs deps, and serves the API + UI together.

# clone & run
git clone https://github.com/danlex/tvl-youtube-extractor.git
cd tvl-youtube-extractor
./run.sh        # → open http://localhost:8000

Headless CLI (no server)

One shot straight to a self-contained summary.html:

./extract.sh "https://youtu.be/VIDEO_ID" --lang Romanian --open

Development

./dev.sh        # FastAPI :8000 + Next.js dev :3000
Self-hosting on a server? YouTube blocks most datacenter IPs with a bot-check, so yt-dlp downloads fail from typical cloud VMs. Run it locally, or pass cookies / a proxy to yt-dlp (--cookies, --proxy).
4 Configuration

Optional .env

Copy backend/.env.example → backend/.env. Everything has a sane default.

VariableDefaultWhat it does
ANTHROPIC_API_KEY—use the API instead of your claude session
TRANSCRIBE_PREFERcaptionscaptions (YouTube subs first) or asr
ASR_BACKENDfaster-whisperor whisper-cli
ASR_MODELbase.entiny.en / base.en / small.en …
RESEND_API_KEY + MAIL_FROM—email the result link (the /api/submit flow)
5 Updating

Stay current

  • Skill & command: re-run the one-liner — it pulls the latest and re-wires everything.
  • The app: git pull in the repo, then ./run.sh (delete frontend/out to rebuild the UI).
# update the skill/command
curl -fsSL https://raw.githubusercontent.com/danlex/tvl-youtube-extractor/main/install.sh | bash
# update the app
cd tvl-youtube-extractor && git pull && ./run.sh
