Install & use

Get it running.

Two ways in — a one-line skill for Claude Code, or the full local app. No API key — it runs through your logged-in Claude session.

Install it ❯ /tvl-extract https://youtu.be/…
Install

Two ways in.

A

The skill & command

One line — adds /tvl-extract and the skill to Claude Code.

# paste into your terminal
curl -fsSL https://raw.githubusercontent.com/danlex/tvl-youtube-extractor/main/install.sh | bash

Then: /tvl-extract https://youtu.be/… Romanian

B

The full app

Clone and run it locally — serves the UI + API at localhost:8000.

git clone https://github.com/danlex/tvl-youtube-extractor.git
cd tvl-youtube-extractor && ./run.sh

Prereqs: brew install yt-dlp ffmpeg · Python 3.10+

How to use it

Get a summary in one step.

Every method takes one input — a YouTube link — and gives you a page with the story timeline, frames, a clip per beat, and a bilingual transcript. Here's a real clip + the finished page:

summary.html
Easiest

Ask Claude

  1. Open Claude Code.
  2. Type /tvl-extract <link> Romanian.
  3. It builds and opens the page.

Or just say “summarize this YouTube video: <link>”.

Browser

The web app

  1. ./run.sh → open localhost:8000.
  2. Paste a link, pick a language.
  3. Click Extract, watch, download.
Terminal

Headless CLI

  1. Run ./extract.sh "<link>" --lang Romanian --open.
  2. It prints & opens one summary.html.
Any language. Change the second argument — French, Spanish, German, English… The English transcript is always kept beside the translation.
Prerequisites

What you need.

ToolWhy
yt-dlp, ffmpeg, ffprobedownload the video, cut frames & clips
Claude Code, logged inthe agent — uses your Claude session, no API key
Python 3.10+the backend
Node 18+ (optional)only to build the web UI — not needed for the CLI/command
Transcription needs no setup. It uses the video's YouTube captions when present, and falls back to faster-whisper (installed via pip, int8 on CPU) when there are none. No whisper.cpp required.
Configuration

Optional .env.

Copy backend/.env.example → backend/.env. Everything has a sane default — you don't need any of these.

VariableDefaultWhat it does
TRANSCRIBE_PREFERcaptionscaptions (YouTube subs first) or asr
ASR_MODELbase.enfaster-whisper model (tiny.en, base.en, …)
ANTHROPIC_API_KEY— (optional)only if you'd rather use the API than your Claude session
RESEND_API_KEY + MAIL_FROM—email the result link (the /api/submit flow)
