Use it

Three ways to run it.

01

The slash command

Quickest path, in any Claude Code session — runs it and opens the result.

/tvl-extract https://youtu.be/ID Romanian
02

The headless CLI

One shot straight to a summary.html; prints the path.

./extract.sh "URL" --lang Romanian --open
03

The web app

A local page: live progress, interactive timeline, download.

./run.sh # → localhost:8000
Hands-free

Or just ask Claude.

With the skill installed you don't even need the command — say what you want and Claude runs the tool for you.

# any of these fire the tvl-youtube-extractor skill
“summarize this YouTube video: <url>”
“break this video into a story timeline”
“transcribe <url> with a Romanian translation”
Under the hood

Link in, legible page out.

01yt-dlpdownload the video
02ffmpegframes + a clip per beat
03whispertranscribe → timed lines
04Claude agentmap the story, translate
05renderself-contained HTML
No API key. The agent authenticates off your logged-in claude session — nothing to configure. Set ANTHROPIC_API_KEY to use the Anthropic API instead, and change the language with the second argument.
Install

One line. That's it.

Installs the /tvl-extract command and the skill into Claude Code.

# paste into your terminal
curl -fsSL https://raw.githubusercontent.com/danlex/tvl-youtube-extractor/main/install.sh | bash

Then, in a new Claude Code session: /tvl-extract https://youtu.be/… Romanian
