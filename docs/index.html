Usage

Three ways to run it.

In any Claude Code session

The slash command

The quickest path — runs the extractor and opens the result.

/tvl-extract https://youtu.be/ID Romanian
Terminal · no server

The headless CLI

One shot straight to a summary.html; prints the path.

./extract.sh "URL" --lang Romanian --open
Interactive · reusable

The web app

Local page: live progress, interactive timeline, download.

./run.sh # localhost:8000

Hands-free

Or just ask Claude.

With the skill installed you don't need the command — say what you want and Claude runs the tool:

# any of these trigger the tvl-youtube-extractor skill
“summarize this YouTube video: <url>”
“break this video down into a story timeline”
“get me the transcript of <url> with a Romanian translation”

Install

Add the command & skill to Claude Code.

# clone the repo
git clone https://github.com/danlex/tvl-youtube-extractor.git
cd tvl-youtube-extractor

# install the slash command + skill (user scope)
cp .claude/commands/tvl-extract.md ~/.claude/commands/
cp -r .claude/skills/tvl-youtube-extractor ~/.claude/skills/

Start a new session and /tvl-extract plus the skill are available everywhere.

Under the hood

How it works.

1yt-dlpdownload the video
2ffmpegframes + a clip per beat
3whispertranscribe → timed lines
4Claude agentmap the story, translate
5renderself-contained HTML
No API key.  The agent authenticates off your logged-in claude session — nothing to configure. Set ANTHROPIC_API_KEY to use the Anthropic API directly instead. Change the language with the second argument: French, Spanish, German, and more.
