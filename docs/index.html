Claude Code · Skill & Command

Turn a YouTube video into a story-timeline page.

Paste a link. A Claude agent watches the whole transcript, maps it into a narrative arc, pulls every frame and a short clip per beat, and writes the full transcript with a translation — all into one self-contained HTML page.

❯ /tvl-extract https://youtu.be/… Romanian

What you get

🗺️

Story timeline

A color-coded act/beat graph of the whole video.

🎞️

Per-beat clips

A short looping clip cut at each story beat.

🖼️

Every frame

A timestamped frame gallery, one every 5 seconds.

🌍

Bilingual transcript

The full captions next to a translation.

Three ways to run it

In any Claude Code session

1 · The slash command

The quickest path. The command runs the extractor and opens the result.

/tvl-extract https://youtu.be/dQw4w9WgXcQ Romanian
Terminal · no server

2 · The headless CLI

One shot straight to a summary.html. Prints the file path.

./extract.sh "https://youtu.be/VIDEO_ID" --lang Romanian --open
Interactive · reusable

3 · The web app

A local page with live progress, an interactive timeline, and a download button.

./run.sh   # then open http://localhost:8000

Just talk to Claude

With the skill installed you don't even need the command. Say what you want and Claude runs the tool:

# any of these trigger the tvl-youtube-extractor skill
“summarize this YouTube video: <url>”
“break this video down into a story timeline”
“get me the transcript of <url> with a Romanian translation”

Install the command & skill

# clone the repo
git clone https://github.com/danlex/tvl-youtube-extractor.git
cd tvl-youtube-extractor

# install the slash command + skill into Claude Code (user scope)
cp .claude/commands/tvl-extract.md ~/.claude/commands/
cp -r .claude/skills/tvl-youtube-extractor ~/.claude/skills/

Start a new Claude Code session and /tvl-extract and the skill are available everywhere.

How it works

1yt-dlpdownload the video
2ffmpegframes + a clip per beat
3whispertranscribe → timed lines
4Claude agentmap the story, translate
5renderself-contained summary.html

No API key — it uses your session

The agent authenticates off your logged-in claude CLI session, so there is nothing to configure. Each video costs roughly $0.10–0.25 per Claude call (two per video) against your session. Set ANTHROPIC_API_KEY to use the Anthropic API directly instead.

Tip  Change the translation language with the second argument — /tvl-extract <url> French, Spanish, German, and more.
